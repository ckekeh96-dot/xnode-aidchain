Add the local AidChain test chain to MetaMask

This page only asks MetaMask to add and switch to your own local anvil chain. It holds no keys and sends no transactions. Local development helper — not part of the demo journey.

Open this page over http://localhost:8080 (run python -m http.server 8080 in the package folder). MetaMask does not inject into file:// pages unless you enable file-URL access for the extension.

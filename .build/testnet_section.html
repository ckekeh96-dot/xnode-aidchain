Connect a wallet to an independently deployed AidChain escrow on Ethereum Sepolia or a local anvil test chain. Demo tokens only. The offline showcase continues to work without a wallet.

Experimental testnet integration. Requires internet, a browser wallet (or the one-click local demo panel below), your own deployed demo contracts, and Sepolia ETH for gas (a local anvil chain needs none). Supported networks: Ethereum Sepolia (11155111) and local chain 31337 — anything else, mainnet included, is refused at connect time. Never enter private keys or seed phrases anywhere in this page. No contract is audited. On-chain receipts are issued only after a transaction reaches status = success in a mined block.

One click installs the built-in demo wallet for the local chain, connects it and validates the deployed contracts — for demos on a machine without MetaMask. It holds no private keys and moves only valueless demo tokens; each role switch reconnects and re-validates automatically. A public website cannot reach a visitor's localhost, so for remote judging use the Sepolia flow with MetaMask instead.

Guided run — use the numbered panels below:

  1. NGO — panel 2: create a project (reviewer is pre-filled; target 1000 is the ready-made 25/50/25 sample).
  2. Donor — panel 3: mint 300 demo USDC, then Approve & donate 300 to the new project.
  3. NGO — panel 4: submit evidence for milestone 0.
  4. Reviewer — panel 4: approve the milestone.
  5. NGO — panel 4: release funds — the receipt is issued only after the transaction is mined.
  6. Donor — panel 5: claim the refundable remainder.
  7. Anyone — On-chain audit: sync events to read every step straight from the chain.
